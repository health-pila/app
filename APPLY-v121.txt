1DAY PT 새 신청 알림
- 기존에는 신청 목록 갱신만 있었고 알림음에는 연결되지 않았습니다.
- 1DAY PT 새 신청을 기존 공통 알림음에 연결했습니다. 별도 버튼 추가 없음.
- 기존 알림음 켜기·끄기·테스트가 루틴 신청·회원 문의·1DAY PT에 함께 적용됩니다.
- 관리자가 완료/취소 등 어떤 목록 필터를 보고 있어도 알림을 확인합니다.
- 실시간 갱신 및 30초 간격 확인을 함께 사용합니다.
- 관리자 화면을 열어둔 동안 다른 브라우저 탭으로 이동해도 알림 확인을 계속합니다.
- 최초 목록에 있던 기존 신청, 같은 신청의 반복 조회, 처리 상태 변경에는 알림음을 내지 않습니다.
- 브라우저 탭 제목의 건수에도 1DAY PT 대기 신청을 포함합니다.
- 최근 1,000건의 ID·상태·생성 시각만 읽어 확인하며 신청 데이터는 수정하지 않습니다.
- 로그아웃/회원 화면 전환 시 알림 확인 중지 및 늦은 응답 차단.

아래 5개 파일을 기존 프로젝트 루트에 덮어쓴 뒤 커밋·푸시하세요.
index.html
reset-password.html
service-worker.js
one-day-pt.js
admin-routine-alerts.js

APPLY-v121.txt는 안내문이므로 앱 폴더에 복사하지 않아도 됩니다.

검증
- JS 구문, 변경 파일 범위, 새 알림음 버튼 없음
- 기존 루틴 신청·회원 문의 알림 동작 보존
- 1DAY PT 초기 목록 무음·새 신청·반복/상태 변경 무음·공통 알림음 끄기
- 실제 두 모듈을 모의 환경에서 함께 실행해 필터 독립 확인·백그라운드 탭·30초 확인 검증
- 알림 확인 실패/복구·로그아웃 후 타이머 및 늦은 이벤트 차단·회원 모드 분리
- 운영 DB 쓰기 테스트와 실제 브라우저 소리 재생은 수행하지 않았습니다.

브라우저의 기존 소리 자동 재생 제한은 동일하게 적용됩니다.
배포 후 관리자 화면에서 소리 테스트 및 새 1DAY PT 신청을 확인해 주세요.
