센터앱 v120 교체 안내 (푸시 완료 v119 기준)

관리자 화면
- 요청한 설명 문구 및 중복 알림음 안내 삭제
- 표시 순서: 1DAY PT 신청 → 루틴 신청·회원 선택·루틴 편집 통합 영역 → 회원 1:1 문의 관리 → 기존 소식 관리
- 새 운동 구성 신청과 회원 선택을 같은 박스로 연결
- 신청 목록에서 회원 선택 시 기존처럼 회원 선택 영역으로 스크롤

루틴 이름 선택 입력
- JSON 및 기존 이미지 루틴 모두 이름을 비워도 적용 가능
- 새 루틴은 ‘맞춤 운동 루틴’으로 이름 자동 입력
- 기존 루틴 수정에서 이름을 비우면 기존 이름 유지
- 직접 입력한 이름은 그대로 사용

알림음
- 관리자 화면 진입 시 기본 켜짐
- 브라우저가 허용하면 즉시 소리 준비, 차단 중이면 관리자 화면의 첫 클릭·키보드 동작으로 자동 활성화
- 화면 진입 시 확인용 소리는 내지 않음
- 최초 목록에 이미 있던 신청·문의는 소리 없이 표시하고, 이후 새 신청·메시지에 알림
- 두 알림 설정은 함께 켜고 끌 수 있으며, 소리 테스트는 그대로 제공
- 직접 끄면 해당 관리자 세션에서 끄기 유지. 새로고침·재진입 시 기본 켜짐
