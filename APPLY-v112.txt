JSON 생성 연결:
JSON 생성용 DB 엑셀 사본의 EX039 난이도도 4로 수정.
별도로 제공한 05_운동DB_MASTER_난이도4반영_v112.xlsx를 JSON 생성 프로젝트에 업로드해 기존 DB 첨부파일을 교체.
드라이브 파일 변경이 별도로 업로드된 프로젝트/GPT 지식 파일까지 자동 갱신하는 것은 아님.

현재 확정 규칙에 따른 새 JSON:
- 실제 최대 난이도 4 이상인 회원에게만 EX039를 후보로 검토.
- 일반 난이도 4 운동이므로 reps:12, restSec:90.
- sets는 기존 시간/보너스 패턴 규칙으로 결정.
- exerciseId는 EX039 유지. JSON에 difficulty 등의 새 필드를 추가하지 않음.
- days/day/exercises의 기존 형식 유지.

이미 배정된 회원 루틴의 reps/sets/restSec는 자동으로 변경하지 않음.
앱은 저장된 JSON의 숫자를 그대로 표시하며, 운동 DB 난이도를 바꿔도 기존 처방을 재작성하지 않음.
이번 작업은 해당 변경의 반영이며 지속적인 시트 자동 동기화 기능은 추가하지 않음.

검증: 수정 JS 문법, 운동DB 변경 범위, JSON 연결 확인.
