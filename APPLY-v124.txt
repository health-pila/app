센터앱 v124 — 종목변경 화면 간소화
기준: v123

[적용]
압축파일의 아래 앱 파일 6개를 기존 프로젝트 폴더에 덮어씁니다.
index.html
reset-password.html
service-worker.js
routine-components.js
member-exercise-replacements.js
member-exercise-replacements.css

버전과 PWA 캐시는 v124로 맞췄습니다.
Supabase SQL은 변경하지 않았으며 추가 실행이 필요하지 않습니다.
알림음 수동 수정, 안내 글자, 기존 기능과 운동 데이터는 그대로 유지합니다.
이 안내문은 앱 폴더에 복사하지 않아도 됩니다.

[변경]
- 카드의 변경 버튼을 운동 이름 오른쪽 위로 이동하고 종목변경으로 표시합니다.
- 선택창 제목도 종목변경으로 통일합니다.
- 요청한 안내 문구 3종을 삭제합니다.
- 저장 전 확인 체크박스와 해당 안내를 삭제합니다.
- 운동 선택 후 확인하고 저장 버튼으로 바로 저장합니다.
- 세트·횟수·휴식 입력 검증, 저장 오류 확인, 원본 복원, 새 루틴 초기화는 유지합니다.

[커밋 메시지]
v124: 종목변경 버튼 위치 및 선택창 간소화

[확인]
1. 배포 후 새로고침해 운동 이름 오른쪽 위의 종목변경을 누릅니다.
2. 추천/전체 운동 선택, 값 확인 후 체크박스 없이 저장합니다.
3. 새로고침 후 변경 유지, 상세설명·영상·중량 기록·PT 종목을 확인합니다.
4. 원래 운동으로 복원도 추가 체크박스 없이 가능한지 확인합니다.
5. 작은 화면과 PC에서 긴 운동 이름과 버튼이 겹치지 않는지 확인합니다.
