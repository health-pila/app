v81 — 가입 전에 둘러보기

적용 방법
1. 아래 5개 파일을 기존 프로젝트의 같은 이름 파일에 덮어씁니다.
   index.html / style.css / routine-components.js / reset-password.html / service-worker.js
2. guest-demo.js를 index.html과 같은 폴더에 새로 추가합니다.
3. 압축 안의 images/demo 폴더를 프로젝트의 images 폴더 안으로 복사합니다.
   기존 images 폴더를 지우거나 통째로 교체하지 말고, demo 하위 폴더만 추가하세요.
   포함 사진: leg-press.jpg / lat-pulldown.jpg / chest-press.jpg
4. 버전은 모두 81로 맞춰두었습니다.

푸시 명령

git add index.html style.css routine-components.js reset-password.html service-worker.js guest-demo.js images/demo
git commit -m "v81: 가입 전 운동 루틴 체험 화면 추가"
git push

새 기능
- 로그인 화면에 ‘가입 전에 둘러보기’ 버튼이 생깁니다.
- 레그프레스/랫 풀 다운/체스트 프레스 3종목을 체험할 수 있습니다.
- 기존 운동 카드의 상세설명, YouTube 영상, 기구 사진 확대 기능을 사용합니다.
- 중량/횟수/코멘트를 5세트까지 입력하고 즉시 초기화할 수 있습니다.
- 체험 기록은 메모리에만 보관하고 창을 닫으면 지웁니다.
- 사진과 손글씨 메모가 있는 운동 다이어리 예시를 보여줍니다.
- 하단 ‘내 운동 루틴도 추천받기’를 누르면 기존 회원가입 화면으로 이동합니다.
- 닫기/Esc/브라우저 뒤로가기로 로그인 화면에 돌아올 수 있습니다.
- 체험 종료 시 영상 재생과 확대 사진도 정리합니다.

기존 기능 보존
- 회원 정보와 실제 루틴을 조회하지 않으며, 체험 중 DB를 읽거나 쓰지 않습니다.
- 체험 기록은 회원의 중량 기록/장바구니와 섞이지 않습니다.
- 체험에서 PT 신청이나 실제 운동 구성 신청은 발생하지 않습니다.
- script.js / admin-routine-alerts.js / one-day-pt.js / exercise-data.js는 수정하지 않았습니다.
- 관리자 알림음 0.8, 최신 신청 안내창 문구, 사진 확대, 초기화 즉시 삭제를 유지했습니다.
- 사진 3장은 기존 운동 DB의 공개 기구 사진을 체험 화면용으로 함께 제공합니다.

배포 후 확인
1. 로그인하지 않은 화면에서 ‘가입 전에 둘러보기’를 누릅니다.
2. 상세설명/영상/중량 기록/사진 확대를 눌러봅니다.
3. 기록 입력 후 창을 닫았다 다시 열어 체험 기록이 비워지는지 확인합니다.
4. ‘내 운동 루틴도 추천받기’가 회원가입 화면으로 연결되는지 확인합니다.
5. 휴대폰 뒤로가기와 로그인/회원가입 기능이 정상인지 확인합니다.

검증 범위
- 실제 앱의 HTML/CSS/JS를 로컬 Chromium에서 실행하고, 인증/DB는 테스트 응답으로 대체했습니다.
- 320px/390px/1280px 화면 크기에서 레이아웃, 상세설명, 영상 삽입/제거,
  확대 사진, 체험 기록 15칸, 초기화, 뒤로/앞으로가기, 닫기/Esc, 가입 연결을 확인했습니다.
- 체험 중 DB 호출/브라우저 저장 변경이 없고 기존 회원 기록은 계속 저장됨을 확인했습니다.
- 저장 공간 접근이 차단된 상태에서도 체험 기록 입력을 확인했습니다.
- 서비스워커에 새 JS와 사진 3장이 포함되고 모든 캐시 대상 경로가 열리는지 확인했습니다.
- 실제 YouTube 영상의 재생은 외부 서비스/네트워크에 따라 달라집니다. 배포 후 휴대폰에서도 확인해 주세요.
