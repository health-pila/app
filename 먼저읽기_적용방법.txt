센터앱 v154 — 운동 종목 추가하기 버튼 디자인

적용 방법
1. 압축의 ‘교체파일’ 폴더 안 5개 파일을 기존 개발 폴더의 같은 위치에 덮어씁니다.
2. 폴더 자체를 앱 안에 넣지 말고, 안의 5개 파일만 복사합니다.
3. 새 이미지 등록과 SQL 실행은 필요 없습니다.
4. 커밋·동기화 후 새로고침 또는 앱을 완전히 닫고 다시 열어 확인합니다.

변경 사항
- 버튼 글자: 운동 종목 추가하기
- 기존 글자 크기 13px 유지
- 예시처럼 연한 주황 배경·주황 테두리·왼쪽 원형 플러스·오른쪽 화살표 적용
- 버튼 위 구분선: 기존 운동 카드 구분선 3px의 70%인 2.1px
- 아이콘은 SVG/CSS로 표시하므로 별도 이미지 파일이 필요 없습니다.
- 기존 클릭·비활성화 처리와 운동 추가·저장 로직은 유지합니다.
- PWA 버전 154로 갱신합니다.

확인
- 320px/390px 모바일 및 1280px PC에서 버튼·글자·아이콘 배치를 확인했습니다.
- 글자 크기 13px, 기존 구분선 3px와 신규 구분선 CSS 2.1px를 확인했습니다.
- 브라우저 내부 픽셀 반올림 때문에 실제 계산값은 약 2.094px로 표시될 수 있습니다.
- 일반 패턴과 기존 보너스 패턴 버튼 클릭 시 기존 운동 선택창이 열리는 것을 확인했습니다.
- 저장소 확인 전 비활성화 동작을 유지합니다.

복원 방법
‘참고자료/변경전_v153’ 폴더의 5개 파일을 기존 개발 폴더에 덮어쓰고 다시 배포합니다.
회원 루틴·추가 운동·교체 설정·개인 운동 목록·운동 기록은 변경하거나 삭제하지 않았습니다.
