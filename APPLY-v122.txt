[사용 방법]
- 관리자 화면: '회원 1:1 문의 관리' 아래에 '스트레칭 영상 관리'가 추가됩니다.
- 영상 제목과 유튜브 쇼츠 URL을 입력하고 '영상 등록'을 누르세요.
- https 유튜브 쇼츠 주소, youtu.be 공유 주소, 일반 watch 영상 주소를 지원합니다.
- '표시 순서'가 작은 영상이 먼저 나옵니다. 같은 숫자라면 최근 등록 영상이 먼저 나옵니다.
- '회원에게 공개'를 끄면 회원 목록에서 숨깁니다. 관리자는 계속 미리보기·수정할 수 있습니다.
- 수정, 공개/숨김 전환, 삭제가 가능합니다. 삭제해도 유튜브 원본은 삭제되지 않습니다.
- 회원 화면: 운동 구성 → 나의 루틴 / 유산소 / 스트레칭.
  세 탭이 들어가도록 표시 명칭 '유산소 프로그램'을 '유산소'로 줄였습니다.
- 썸네일 두 열에서 영상을 누르면 앱 안의 9:16 세로 창에 선택한 영상 하나만 열립니다.
  자동으로 다음 영상으로 넘어가지 않습니다. 닫기·뒤로가기로 기존 목록 위치에 돌아옵니다.
- 목록은 스트레칭 탭을 열 때 조회하고, 같은 접속에서는 최대 1분간 메모리 캐시를 사용합니다.
  '새로고침'을 누르면 최신 목록을 바로 조회합니다.
- 썸네일은 지연 로딩하고, 플레이어는 선택 전에는 생성하지 않습니다.
  닫기·탭 이동·로그아웃·페이지 이탈 시 iframe을 제거합니다.
- 등록 전에는 '스트레칭 영상을 준비 중이에요.'가 표시됩니다.
  네이버 클립 내용이나 기존 유튜브 영상은 자동으로 가져오지 않았습니다.

[배포 후 확인 — 실제 계정/영상]
1. 관리자 계정에서 실제 쇼츠 한 개를 제목·URL과 함께 등록해 주세요.
2. 회원 계정의 스트레칭 탭에 썸네일·제목이 나오는지 확인해 주세요.
3. 영상을 눌러 세로 재생, 닫기, 뒤로가기, 목록 위치 복귀를 확인해 주세요.
4. 관리자에서 순서·제목·공개 여부를 바꾸고, 회원 목록의 새로고침으로 반영을 확인해 주세요.
5. 기존 루틴·유산소·휴식 타이머·운동 기록·PT·문의도 평소처럼 열리는지 확인해 주세요.
6. 유튜브의 임베드 허용 여부/브라우저 재생 정책은 실제 영상으로 확인해야 합니다.
   재생 정책에 따라 영상 안의 재생 버튼을 한 번 더 눌러야 할 수 있습니다.
   재생 불가 영상은 'YouTube에서 보기' 링크로 열거나 다른 영상 URL로 바꿔 주세요.
   유튜브의 기본 로고·조작 버튼은 유지합니다. 플레이어 자체는 잘라 확대하지 않습니다.

[설정이 안 된 경우]
- 회원 화면은 준비 중 안내를 표시하고 다른 기능은 계속 사용할 수 있습니다.
- 관리자에 '저장소 설정이 필요합니다'가 나오면 2번 SQL 실행을 확인한 뒤 '목록 새로고침'을 누르세요.
- 권한 오류가 나면 관리자 계정의 기존 profiles.role이 admin인지 확인해 주세요.
  SQL은 기존 profiles의 권한 정책을 수정하지 않습니다.

[검증 범위]
- 로컬 Chromium에서 실제 앱 HTML/CSS/JS를 실행했습니다.
- 320/360/390/430/768px 화면, 세 탭 이동·키보드 전환, 단일 iframe 생성/제거,
  닫기·뒤로가기·Escape·탭 이동·로그아웃, 목록 스크롤/포커스 복귀를 확인했습니다.
- 관리자 등록/수정/숨김/삭제, URL 검증, 중복 등록, 동시 수정 충돌,
  저장소 미설정 후 재조회, HTML 텍스트 안전 표시, 늦은 응답/계정 전환 분리를 확인했습니다.
- 별도 PostgreSQL 테스트 환경에서 SQL 실행/재실행, 관리자 CRUD,
  회원의 공개 영상 조회·쓰기 차단, 비로그인 접근 차단, 입력 제약을 확인했습니다.
- 모든 JS 구문, 캐시 파일 경로/버전, 중복 HTML ID, 기존 주요 파일 보존을 확인했습니다.
- 브라우저 검증의 로그인/DB/유튜브 응답은 테스트 대체 응답을 사용했습니다.
  운영 Supabase에는 접속하거나 SQL을 실행하지 않았고 실제 유튜브 재생 검증은 배포 후 필요합니다.
