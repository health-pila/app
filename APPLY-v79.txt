v79 — 관리자 운동 루틴 신청 알림

적용 방법
1. 아래 5개 파일을 같은 이름의 기존 파일에 덮어씁니다.
   index.html / style.css / script.js / reset-password.html / service-worker.js
2. 새 파일 admin-routine-alerts.js를 index.html과 같은 폴더에 추가합니다.
3. 버전 번호는 모두 79로 맞춰두었습니다. 별도로 바꿀 필요 없습니다.
4. 아래 명령으로 푸시합니다.

git add index.html style.css script.js reset-password.html service-worker.js admin-routine-alerts.js
git commit -m "v79: 관리자 루틴 신청 탭 배지와 알림음 추가"
git push

사용 방법
- 관리자 화면의 ‘새 운동 구성 신청’ 영역에 ‘새 신청 알림’이 추가됩니다.
- 대기 중인 신청이 있으면 탭 아이콘에 빨간 점, 제목에 (신청 N건)을 표시합니다.
- N은 아직 처리하지 않은 전체 대기 신청 건수입니다. 목록을 읽었다고 사라지지는 않습니다.
- 대기 신청이 처리되어 목록에서 없어지면 건수도 줄고, 0건이면 점과 건수가 사라집니다.
- ‘알림음 켜기’를 누르면 테스트 소리가 한 번 울리고, 이후 새 신청에 짧은 두 음이 울립니다.
- ‘소리 테스트’는 소리만 재생합니다. 자동 알림음을 켜거나 끄지는 않습니다.
- 새로고침/새 창/재로그인 후에는 ‘알림음 켜기’를 다시 눌러주세요.
- 처음 목록을 불러올 때 이미 있던 신청은 건수만 표시하고 소리는 내지 않습니다.
- 같은 신청을 반복 조회해도 다시 울리지 않습니다. 같은 ID의 재신청은 신청 시각으로 구분합니다.
- 같은 브라우저의 동일 관리자 계정에서 여러 탭을 열면 Chrome의 탭 간 잠금과 저장된 이력으로 중복 소리를 막습니다.
- 관리자 로그아웃 또는 회원 화면 전환 시 점/제목/알림음을 초기화합니다.

확인 방법
1. 배포 완료 후 관리자 화면을 열고 ‘알림음 켜기’를 누릅니다.
2. ‘소리 테스트’로 PC 볼륨과 탭 음소거 여부를 확인합니다.
3. 다른 회원 계정으로 실제 운동 루틴 신청서 한 건을 제출합니다.
4. 관리자 탭에 신청 건수/빨간 점이 표시되고 소리가 한 번 나는지 확인합니다.
5. 해당 루틴을 배정해 대기 목록에서 빠지면 건수가 줄어드는지 확인합니다.

범위와 제한
- 관리자 탭을 열고 로그인한 동안의 알림입니다. 탭을 닫으면 알림이 오지 않습니다.
- PC 절전, 탭 절전, 네트워크 단절 상태에서는 즉시 전달되지 않을 수 있습니다.
- 기존 신청 DB 실시간 연결을 사용합니다. SQL/Google Apps Script 수정이나 문자·푸시 서비스 가입은 필요 없습니다.
- 이 기능은 신청 데이터를 읽기만 합니다. 회원 정보, 루틴 배정, 문자 발송은 변경하지 않습니다.
- v78의 사진 확대, 초기화 확인창 제거, ‘이번 운동 루틴 안내’ 문구를 유지했습니다.

검증
- 실제 HTML/CSS/JS를 로컬 Chromium에서 실행하고 DB/auth 응답만 테스트 데이터로 대체했습니다.
- 신규/반복/재신청, 실시간 콜백, 처리 완료, 새로고침, 여러 탭 중복 방지,
  음소거/소리 테스트, 소리 재생 및 저장 실패, 로그아웃, 화면 배치를 확인했습니다.
- 실제 Web Audio 호출과 서비스워커의 새 파일 캐시도 확인했습니다.
- 실제 회원 DB 변경이나 문자 발송은 하지 않았습니다. PC 스피커의 실제 청음은 위 방법으로 확인해 주세요.
