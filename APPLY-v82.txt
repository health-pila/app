아래 5개 파일을 기존 프로젝트의 같은 이름 파일에 덮어씁니다.
index.html

reset-password.html
service-worker.js

v81 체험 화면의 guest-demo.js와 images/demo 폴더는 그대로 유지해 주세요.

푸시

git add index.html script.js admin-routine-alerts.js reset-password.html service-worker.js
git commit -m "v82: 관리자 회원 문의 탭 배지와 알림음 추가"
git push

작동 방식
- 관리자 ‘회원 1:1 문의 관리’ 영역에도 알림음 켜기/끄기와 소리 테스트를 추가했습니다.
- 루틴 신청 영역 또는 문의 영역 중 어느 쪽에서 켜도 두 종류 알림이 함께 켜집니다.
- 소리 크기는 확정한 0.8을 유지했습니다.
- 탭 제목 예: (신청 2건 · 문의 3건) 헬스와 필라테스
- 문의 건수는 보관되지 않은 ‘답변 대기’ 문의 수입니다. 메시지 개수가 아닙니다.
- 신청/문의 중 하나라도 남아 있으면 탭 아이콘에 빨간 점이 표시됩니다.
- 새 문의 또는 기존 문의에 회원이 추가 글을 남기면 알림음이 납니다.
- 관리자 답변이나 보관함 복원만으로는 소리가 울리지 않습니다.
- 문의 건수는 현재 보고 있는 ‘답변 대기/답변 완료/보관함’ 필터나 ‘더 보기’와 무관합니다.
- 루틴 신청과 문의 건수는 서로 덮어쓰지 않고 함께 표시됩니다.
- 같은 브라우저에서 같은 관리자 계정의 여러 탭을 열어도 동일 문의의 소리는 한 번만 울립니다.
- 처음 접속했을 때 기존 문의는 건수만 표시하고 소리는 내지 않습니다.
- 관리자 탭을 열어두어야 하며 새로고침 후에는 알림음을 다시 켜야 합니다.
- PC/탭 절전 또는 네트워크 단절 상태에서는 알림이 늦어질 수 있습니다.

유지한 기능
- 가입 전 둘러보기와 3종목 체험, 다이어리 샘플 유지
- 관리자 루틴 신청 알림, 회원 문의 작성/답변/보관/복원, 루틴 배정 기능 유지
- 회원 개인정보나 문의 본문을 알림용 저장소에 보관하지 않습니다.
- 알림용으로 문의 식별자, 상태, 보관 여부, 작성/마지막 메시지 시각만 조회합니다.

배포 후 확인
1. 관리자 화면에서 알림음 켜기, 소리 테스트를 눌러봅니다.
2. 다른 회원 계정에서 새 문의를 남깁니다.
3. 탭 빨간 점/문의 건수/알림음이 나오는지 확인합니다.
4. 관리자 답변 후 문의 건수가 줄고 소리는 나지 않는지 확인합니다.
5. 같은 문의에 회원이 추가 글을 남기면 다시 알림이 오는지 확인합니다.

검증
실제 HTML/CSS/JS와 로컬 Chromium, 모의 DB 응답으로 다음을 확인했습니다.
신규/추가 문의, 반복 조회, 관리자 답변, 보관함 복원, 필터 전환,
실시간 메시지 콜백, 재연결, 루틴 신청과 건수 병합, 두 탭 중복 방지,
새로고침, 501건 목록 페이지 조회, 조회 실패/음성 재생 실패,
로그아웃 후 늦은 콜백 무시, 모바일 크기 배치, 서비스워커 캐시 경로.
실제 회원 DB 수정이나 메시지 발송은 하지 않았습니다.
