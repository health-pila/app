헬스와 필라테스 v50 — 회원 운동 구성 화면 개편

적용할 파일은 ZIP 최상위의 아래 5개입니다.
  index.html
  style.css
  script.js
  routine-components.js
  service-worker.js

1. 적용
현재 PC 프로젝트를 먼저 한 번 복사해 두세요.
압축을 별도 폴더에 풀고 위 5개 파일만 프로젝트의 같은 위치에 덮어씁니다.
rollback-v49 폴더의 파일은 되돌릴 때만 사용합니다.
exercise-data.js, images 폴더, manifest.json은 기존 파일을 그대로 사용합니다.
SQL이나 Google Apps Script를 다시 실행할 필요가 없습니다.

Cursor 터미널에서 기존 프로젝트 폴더를 연 상태로 실행합니다.

git add index.html style.css script.js routine-components.js service-worker.js
git commit -m "v50 회원 운동 구성 화면 UI 개편"
git push

기존 GitHub Pages 배포가 완료되면 앱을 열고 상단 새로고침 버튼을 누릅니다.
이전 화면이 남으면 앱을 완전히 닫았다가 다시 열어 주세요.
index.html의 파일 버전과 서비스워커 캐시 버전은 모두 50입니다.

2. 반영한 내용
- 상단 실제 센터 로고를 132 × 40px 영역에 표시했습니다.
- 상단 오른쪽에 새로고침 아이콘과 더보기 메뉴를 배치했습니다. 로그아웃은 더보기 안에 있습니다.
- 제목은 주황색으로 "나만을 위해 센터가 짜준 운동 구성"을 두 줄로 표시합니다.
- 연한 회색 배경 위에 운동 패턴을 흰색 영역으로 구분했습니다.
- 패턴을 선택하면 해당 운동 목록이 바로 표시됩니다. 첫 패턴을 기본으로 엽니다.
- 패턴은 실제 배정된 JSON에서 만듭니다. 4개 초과, 연속되지 않은 번호도 지원합니다.
- day 4의 탭 이름은 "보너스", 운동 목록의 이름은 "보너스 패턴"입니다.
- 운동의 상세설명, 영상, 기구 사진 확대 기능을 유지했습니다.
- 상세설명·영상보기 버튼 높이는 33px입니다.
- "이번 운동 구성 안내"는 별도의 회색빛 파란 영역에서 접고 펼칩니다.
- 신청 버튼은 기존 주황색 디자인과 링크를 유지하고 구성 안내 아래로 이동했습니다.
  문구: "✍️ 새 운동 구성 신청하기"
- 하단 세 탭은 선형 아이콘으로 바꾸고 선택된 탭의 주황색 음영과 짧은 주황색 막대를 유지했습니다.
- 휴식 타이머는 운동 영역 오른쪽에서 엽니다. 시작한 뒤 접으면 화면 아래에 남은 시간이 표시됩니다.
- 기존 이미지형 운동 구성과 관리자 미리보기의 접기·펼치기 방식도 유지됩니다.

3. 확인 결과와 배포 후 확인
로컬 Chromium에서 실제 HTML/CSS/JS에 테스트용 조회 결과를 연결해 확인했습니다.
  - 320 / 360 / 390 / 430px 화면에서 가로 넘침 없음
  - 33px 버튼, 로고 크기, 주황색 제목 및 하단 선택 표시
  - 패턴 선택, 방향키·Home·End 이동, 선택 패턴의 영상 닫기
  - 같은 내용 자동 갱신 시 선택 패턴·상세설명·영상 요소·안내 펼침 상태 유지
  - 사진 확대, 하단 탭 이동, 메뉴 열기·닫기
  - 타이머 시작·일시정지·재개·완료·초기화
  - 이미지형 구성으로 전환, 기존 설명 펼치기, 미배정 및 조회 실패 표시
  - 신청 대기 표시, 로그아웃 후 화면과 타이머 초기화
  - CSS/JavaScript 문법과 HTML ID 연결

실제 서버 데이터에 대한 쓰기는 하지 않았습니다.
실제 로그인, 영상 서비스의 재생, 실시간 이벤트 수신, 설치된 PWA의 업데이트는
이번 로컬 테스트 범위에 포함되지 않습니다. 배포 후 휴대폰에서 확인해 주세요.
기존 회원 데이터, JSON 규칙, 접수·배정 처리와 서버 설정은 바꾸지 않았습니다.

4. 이전 화면으로 되돌리기
rollback-v49 폴더는 이 대화에서 만든 직전 v49 화면에 버튼 높이 33px를 반영한 복원본입니다.
PC에서 별도로 수정한 다른 내용이 있다면 1번에서 복사해 둔 프로젝트가 가장 정확한 백업입니다.

rollback-v49 안의 5개 파일을 프로젝트의 같은 위치에 덮어씁니다.
서비스워커와 index.html도 함께 복원해야 이전 화면의 파일 버전이 맞습니다.

git add index.html style.css script.js routine-components.js service-worker.js
git commit -m "v50 UI를 이전 화면으로 복원"
git push

배포가 끝나면 앱을 새로고침하고, 필요하면 완전히 닫았다가 다시 엽니다.
화면 코드만 복원하므로 회원 데이터에 대한 복구 작업은 필요 없습니다.
