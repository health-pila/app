v72 — 로그인 전 설치 및 홈 화면 바로가기 안내

적용 방법
1. 기존 프로젝트를 백업합니다.
2. ZIP의 파일 7개를 기존 프로젝트의 같은 경로에 덮어씁니다.
   index.html, script.js, style.css, reset-password.html, service-worker.js
   images/install-samsung-blocked.png, images/install-samsung-details.png
   이미지 2개는 이전 버전과 동일하며 누락 방지를 위해 포함했습니다.
3. APPLY-v72.txt는 설명서이므로 앱 폴더에 복사할 필요가 없습니다.
4. Cursor 터미널에서 다음 명령을 실행합니다.

   git add index.html script.js style.css reset-password.html service-worker.js
   git add images/install-samsung-blocked.png images/install-samsung-details.png
   git commit -m "v72: 로그인 전 설치 및 홈 화면 안내 추가"
   git push

변경 사항
- 로그인 입력란 위에 설치·안내 버튼을 추가했습니다. 회원가입 화면에서도 표시합니다.
- 크롬: ‘이 앱을 홈 화면에 설치’ → 브라우저 설치 창.
- 삼성 인터넷: ‘이 앱을 홈 화면에 설치’ → 기존 사진 안내 2단계 → 설치.
- 네이버 Android 앱: ‘홈 화면에 바로가기 안내’ → 수동 바로가기 추가 안내.
- 브라우저가 아직 설치 이벤트를 제공하지 않으면 기존 브라우저 메뉴 안내를 표시합니다.
- 설치 완료 이벤트 수신 또는 설치 수락 시 로그인 전·후 설치 버튼을 함께 숨깁니다.
- 설치한 앱의 독립 실행 화면에서는 설치 버튼을 숨깁니다.
- 네이버의 바로가기 생성 여부는 감지할 수 없어 로그인 화면에서는 안내 버튼을 유지합니다.
  로그인 후 하단 설치 버튼은 계속 숨기고 상단 더보기 메뉴에 안내를 유지합니다.
- 로그인/회원가입 처리, 회원·관리자 기능, 문의 제목 제거 등 기존 업무 로직은 유지합니다.

확인 내역
- 로컬 Chromium에서 브라우저 식별값과 설치 이벤트를 모의 적용해 검증했습니다.
- 320/360/390px 화면, 로그인 및 회원가입 화면, 안내 닫기와 초점 복귀,
  설치 취소/실패/완료, 연속 클릭 방지, 기존 로그인 후 설치 흐름을 확인했습니다.
- 서비스워커 캐시 파일의 경로 및 JavaScript 문법 검사를 통과했습니다.
- 실제 스마트폰의 설치 경고창 및 실서버 로그인 테스트는 포함하지 않았습니다.

배포 후 테스트
- 배포 완료 후 페이지를 다시 열고, 기존 화면이면 새로고침합니다.
- 크롬/삼성 인터넷/네이버에서 로그아웃 상태로 접속해 로그인 위 버튼을 확인합니다.
- 크롬/삼성의 실제 설치 시험은 앱이 설치되지 않은 기기 또는 삭제 후 진행합니다.
- 네이버에서 안내에 따라 홈 화면 바로가기를 추가하고 다시 접속합니다.
- 회원가입 화면에서도 버튼을 확인하고, 로그인 후 기존 기능을 확인합니다.
