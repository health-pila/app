v69: 문의 제목 입력 제거 및 내용 미리보기 적용

기준
- 이 대화에 첨부한 v68 전체 프로젝트를 기준으로 수정했습니다.
- 전체 프로젝트가 아닌 변경 파일 묶음입니다.

변경 내용
- 회원: 센터 커뮤니티 > 문의하기에서 제목 입력 없이 문의 내용만 작성합니다.
- 회원 문의 내역과 관리자 목록: 새 문의 글 앞부분을 최대 두 줄로 미리 보여줍니다.
- 목록을 누르면 기존처럼 전체 문의 글과 답변을 확인합니다.
- 기존 문의의 제목과 전체 대화는 그대로 보존됩니다. 예전 문의는 기존 제목이 목록에 표시됩니다.
- 문의 상태, 추가 질문, 관리자 답변, 보관함, 삭제, 실시간 갱신 흐름은 유지합니다.

교체할 파일 5개
index.html
script.js
style.css
reset-password.html
service-worker.js

적용 방법
1. 현재 작업 폴더를 백업합니다.
2. 위 5개 파일을 기존 프로젝트의 같은 위치에 덮어씁니다.
   기존 폴더 전체를 삭제하거나 이 ZIP 내용만으로 교체하지 마세요.
   APPLY-v69.txt는 안내용이며 앱 실행에 필요한 파일은 아닙니다.
3. Cursor에서 변경 내용을 확인한 뒤 커밋하고 GitHub에 푸시합니다.
   커밋명: v69: 문의 제목 입력 제거 및 내용 미리보기 적용
4. 배포가 끝나면 회원·관리자 화면을 새로고침합니다.
   회원 화면에서 문의 내용 입력칸만 있는지 확인합니다.
   이후 접수되는 문의의 미리보기·전체 내용·관리자 답변을 확인합니다.

DB/외부 설정
- SQL 실행, Apps Script 수정, Supabase 설정 변경은 필요 없습니다.
- 기존 create_member_inquiry(p_title, p_body) 호출을 유지합니다.
- 내부 title에는 문의 내용 앞부분(최대 100자)을 자동 저장하고, 전체 내용은 p_body로 전달합니다.
- 기존 회원 문의와 답변 데이터는 수정하거나 삭제하지 않습니다.

버전
- index.html 5곳, reset-password.html 2곳, service-worker.js 1곳: 모두 69.
- reset-password.html은 공통 CSS 캐시 버전을 맞추기 위한 변경입니다.

검증 범위
- JavaScript 문법 검사.
- 로컬 모의 RPC/DOM으로 내용만 전송, 빈 내용·접수 중단 차단, 전문·줄바꿈 보존,
  긴 글·이모지 미리보기, 전송 중 상태, 실패 시 작성 내용 유지 확인.
- 회원/관리자 목록 표시와 예전 문의 펼치기·답변 내역 보존 확인.
- 기존 조회·추가 질문·관리자 답변·보관·삭제 함수가 원본과 동일함을 확인.
- 실제 운영 DB에 테스트 문의를 보내거나 배포하지 않았습니다.
- 브라우저 렌더링 및 실제 휴대폰 화면은 적용 후 확인이 필요합니다.
