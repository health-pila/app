기준: v127

아래 앱 파일 6개를 기존 프로젝트 폴더에 모두 함께 덮어씁니다.
index.html
reset-password.html
service-worker.js
style.css
script.js
routine-components.js

버전과 PWA 캐시 번호는 v128로 맞췄습니다.
Supabase SQL 추가 실행은 없습니다. 이 안내문은 앱 폴더에 복사하지 않아도 됩니다.

[변경 내용]
1. 회원·관리자 공통 상단 헤더: 세로 높이 65px에서 52px로 20% 축소.
   로고는 144×48px에서 115.2×38.4px로 20% 축소했습니다.
   가로 너비는 기존처럼 화면 전체를 사용하며, 새로고침/메뉴 버튼의 44px 크기를 유지합니다.
   기기 안전영역 여백도 유지합니다.
2. 배정된 루틴이 없으면 1DAY PT 장바구니 및 안내 전체를 숨깁니다.
   루틴 확인 중에도 숨기며, JSON/이미지 루틴 배정 확인 후에 표시합니다.
   배정이 해제되거나 다른 회원 계정으로 전환하면 다시 확인합니다.
3. 새 운동 루틴 신청하기: 운동 영역 아래, 이번 운동 루틴 안내 바로 위로 옮겼습니다.
   루틴이 없는 회원은 첫 화면에서 스크롤 없이 볼 수 있습니다.
4. 상세설명: 중요 포인트 → 기대 효과 → 자세 설명 → 호흡 방법 순서입니다.
   중요 포인트 제목만 기존 주황색으로 강조합니다. 운동 DB 내용은 변경하지 않았습니다.
5. 운동 기록: 상단 운동 기록 표제를 삭제하고,
   기구 세팅을 사진으로 남겨두면 좋아요. 문구를 주황색으로 표시합니다.
   달력의 날짜칸 높이와 세로 여백을 10%씩 줄였습니다.
   사진 기록 버튼은 기존 루틴 신청 버튼과 같은 46px 높이로 맞췄습니다.
6. 어떻게 신청할까요? 아래에
   1~3개월에 한 번씩 루틴 변경을 추천해요:)
   문구를 주황색으로 추가했습니다. 새 신청서 작성하기와 같은 16.5px입니다.

[검증]
- 로컬 Chromium에서 320/360/390/430/768/1280px 폭으로 배치 확인
- 320×640px부터 루틴이 없는 회원의 신청 버튼이 하단 메뉴 위에 표시되는지 확인
- 루틴 유무, 로딩, 계정 전환, 배정/해제, 기존 이미지형 루틴의 PT 표시 확인
- 신청 버튼/루틴 안내 순서, 상세설명 첫 항목과 색상, 팝업 안내 확인
- 달력 월 이동/날짜 선택 및 사진 기록 버튼 높이 확인
- 회원별 교체/복원/새로고침/다른 브라우저/회원 분리/패턴 구분/새 루틴 배정 확인
- 상세설명/영상/중량 기록/기록 캡처/PT 연결 및 실패·재시도 확인
- 실제 서비스 워커의 v127 → v128 갱신, 캐시 설치 및 기존 저장값 보존 확인
- JS 문법, 수정 파일 범위, 기존 인증·중량 저장·타이머·알림음·DB 코드 보존 확인
모든 검증은 로컬 테스트 환경입니다. 운영 계정/실물 휴대전화의 최종 확인은 배포 후 진행합니다.
