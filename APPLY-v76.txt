v76: 중량 기록 5세트 입력표

기존 프로젝트의 같은 경로에 아래 5개 파일을 덮어쓰세요.
- index.html
- style.css
- routine-components.js
- reset-password.html
- service-worker.js

현재 배포된 v75를 기준으로 수정했습니다. 커뮤니티 문구/순서, 로그인 화면,
캘린더 크기, 사진 메모 크기와 프레임 여백 등 기존 변경을 유지합니다.
사진 메모의 padding 오타 10x를 앞서 정한 10px로 수정했습니다.
버전은 76으로 통일했으므로 별도의 버전 변경은 필요하지 않습니다.

변경 내용
- 중량 기록을 펼치면 1~5세트별 중량(kg), 횟수, 코멘트를 입력합니다.
- 처음에는 빈 표이며 스크린샷의 예시 숫자가 실제 기록으로 저장되지 않습니다.
- 좁은 화면에서는 표만 좌우로 이동하며 항목 제목은 왼쪽에 고정됩니다.
- 버튼을 누를 때 입력칸에 자동 초점을 주지 않습니다.
- 중량과 횟수는 숫자 입력용 키보드를 요청하고 코멘트는 여러 줄 입력을 지원합니다.
- 회원 계정과 운동별로 현재 브라우저에 자동 저장합니다. 날짜별 이력이나 기기 간 동기화는 없습니다.
- 기존 텍스트 기록은 ‘기존 메모 보기’에 보존합니다.
- 표 오른쪽 위 ‘초기화’ → 확인 시 해당 운동의 5세트 표만 비웁니다.
  다른 운동/다른 회원의 기록과 기존 텍스트 메모는 유지합니다.
- 브라우저 데이터를 지우면 로컬 기록은 삭제될 수 있습니다.

저장 후 Cursor 터미널에서 실행:
git add index.html style.css routine-components.js reset-password.html service-worker.js
git commit -m "v76: 중량 기록 5세트 표 및 초기화 추가"
git push

검증
로컬 Chromium에서 320/390/430px 폭의 표 배치, 입력, 새로고침 복원,
계정/운동별 분리, 초기화 확인/취소, 기존 메모 보존, 저장 실패 시 입력 유지와
재시도, 자동 초점 없음, 캐시 경로를 확인했습니다.
실제 휴대폰 키보드 동작과 실서버 회원 로그인은 배포 후 확인해 주세요.
