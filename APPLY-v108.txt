센터앱 v108 교체 파일 — 휴식 타이머 시작 시 자동 접기

적용 기준: 사용자가 첨부한 v107 전체 프로젝트
변경 내용:
- 휴식 타이머의 시작/계속/다시 시작을 누르면 타이머 창을 자동으로 접습니다.
- 남은 시간은 기존 작은 타이머 버튼에 계속 표시됩니다.
- 버튼을 다시 누르면 진행 중인 타이머 창을 펼칠 수 있습니다.
- 일시정지 버튼은 자동으로 접히지 않습니다.
- 타이머 드래그 기능은 이번 변경에 포함하지 않습니다.

교체 파일 4개:
script.js
index.html
reset-password.html
service-worker.js

적용 순서:
1. ZIP을 별도 폴더에 압축 해제합니다.
2. 위 파일 4개를 기존 프로젝트 폴더의 같은 이름 파일에 덮어씁니다.
3. 변경 사항을 확인한 뒤 커밋/푸시합니다.

추천 커밋 메시지:
v108: 휴식 타이머 시작 시 자동 접기

검증:
- 모든 본편 JavaScript 파일의 문법 검사 통과.
- v107과 비교해 타이머 이벤트의 2줄 추가 및 캐시 버전 변경만 확인.
- 실기기/운영 배포 검증은 아직 하지 않았습니다.

배포 후 확인:
타이머 열기 → 시작 → 자동 접힘 및 남은 시간 표시 확인.
다시 열기 → 일시정지 → 계속 → 자동 접힘 확인.

이 ZIP은 전체 프로젝트가 아닌 변경 파일 교체용입니다.
