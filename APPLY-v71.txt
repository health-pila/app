v71: 네이버 설치 버튼 정리 / 삼성 안내 사진 교체

기준
- 이 대화에서 전달한 v70 프로젝트를 기준으로 수정했습니다.
- v69 문의 제목 제거 및 v70 삼성 설치 안내가 포함되어 있습니다.
- 전체 프로젝트가 아닌 교체 파일 묶음입니다.

수정 내용
1. 안드로이드 네이버 앱에서는 하단의 ‘이 앱을 홈 화면에 설치’ 버튼을 숨깁니다.
   바로가기 추가 전과 후 모두 숨깁니다. 설치 완료를 자동 감지한 것으로 처리하는 방식이 아닙니다.
2. 네이버에서는 회원 화면 상단 ‘···’ 메뉴에 ‘홈 화면 바로가기 안내’를 표시합니다.
   안내에서 네이버 브라우저 메뉴의 ‘바로가기 추가’ 이용 방법을 설명합니다.
   이미 아이콘이 있으면 다시 추가할 필요가 없으며, 웹페이지 형식으로 열린다고 안내합니다.
3. 크롬·삼성 인터넷의 기존 설치 동작과 아이폰 안내는 유지합니다.
4. 삼성 안내 사진 2개를 사용자가 제공한 주황색 동그라미 표시 이미지로 교체합니다.
   기존 코드가 그리던 사각 테두리는 제거하여 표시가 겹치지 않게 했습니다.
5. 앱 캐시 버전과 사진 주소의 버전을 71로 맞췄습니다.

덮어쓸 파일 7개
index.html
script.js
style.css
reset-password.html
service-worker.js
images/install-samsung-blocked.png
images/install-samsung-details.png

적용 방법
1. 현재 프로젝트를 백업합니다.
2. 위 파일 7개를 기존 프로젝트의 같은 경로에 덮어씁니다.
   images 폴더 안에서는 사진 2개만 교체하고 다른 사진은 유지하세요.
   이 ZIP만으로 프로젝트 전체를 교체하지 마세요.
3. Cursor의 프로젝트 터미널에서 아래 명령어를 순서대로 실행합니다.

git add index.html script.js style.css reset-password.html service-worker.js
git add images/install-samsung-blocked.png images/install-samsung-details.png
git commit -m "v71: 네이버 설치 안내 정리 및 삼성 사진 교체"
git push

4. 배포 완료 후 휴대폰에서 새로고침합니다. 예전 화면이 남아 있으면 탭을 닫고 다시 접속합니다.
5. 네이버 홈 화면 바로가기로 접속해 아래 두 항목을 확인합니다.
   - 하단에 설치 버튼이 없는지
   - 상단 ‘···’ 메뉴의 ‘홈 화면 바로가기 안내’를 열고 닫을 수 있는지
6. 삼성 인터넷에서는 설치 버튼을 눌러 새 사진과 설치 연결을 확인합니다.

상태 처리에 관한 설명
- 현재 네이버 바로가기는 일반 웹페이지로 열립니다.
- 앱 설치 완료 이벤트나 독립 앱 실행 상태를 기준으로 하면 바로가기 추가를 알 수 없습니다.
- 그래서 추가 여부를 추측하거나 사용자에게 완료 여부를 다시 입력하게 하지 않습니다.
- 네이버에서 설치 권유를 제거하고 필요할 때 볼 수 있는 메뉴 안내로 바꾼 수정입니다.
- 개인정보나 회원 계정에 ‘설치 완료’를 저장하지 않으며 DB 변경도 없습니다.
- 브라우저 판별은 안드로이드 네이버 앱의 사용자 에이전트 정보를 사용합니다.
  실제 휴대폰에서 여전히 설치 버튼이 보이면, 배포/캐시 및 접속 환경 확인이 필요합니다.

검증
- JavaScript 문법 검사.
- 실제 HTML/CSS와 설치·상단 메뉴 코드를 로컬 브라우저에서 실행하여 확인.
- 네이버 환경을 모의하여 설치 버튼 숨김, 새로고침 후 유지, 설치 이벤트에 의한 재표시 방지 확인.
- 네이버 메뉴 안내 열기/닫기/Escape/키보드 포커스/320px 및 390px 화면 확인.
- 삼성 320/360/390px 사진 안내와 단계 이동, 설치 호출 연결 확인.
- 크롬 설치, 아이폰 안내, 설치된 앱 모드의 기존 분기 확인.
- 캐시에 등록한 파일의 주소가 모두 정상 응답하는지 확인.
- 설치 안내 영역 외 script.js 업무 로직이 v70과 동일함을 확인.
- 운영 사이트에 직접 배포하지 않았으며, 네이버와 삼성 실제 휴대폰 검증은 적용 후 필요합니다.

APPLY-v71.txt는 적용 안내용이며 앱 실행에는 필요하지 않습니다.
