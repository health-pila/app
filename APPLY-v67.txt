v67: 구글 폼 복귀 시 별도 창이 남는 문제 개선

변경 내용
- 처음 운동 구성을 신청하는 링크와 기존 회원의 '새 신청서 작성하기' 링크를
  target="_blank"에서 target="_self"로 변경했습니다.
- 구글 폼을 별도의 새 창이 아닌 현재 앱의 탐색 흐름에서 열도록 합니다.
- 신청 접수·안내 문구·구성만 변경 신청·관리자 처리 코드는 변경하지 않았습니다.
- Google Apps Script, 구글 폼의 복귀 링크, Supabase SQL을 수정할 필요가 없습니다.

적용 방법
1. 아래 3개 파일만 기존 프로젝트의 같은 위치에 덮어씁니다.
   index.html
   service-worker.js
   reset-password.html
2. 저장하고 GitHub에 커밋·푸시합니다. 버전 67은 이미 반영되어 있습니다.
   커밋명: v67: 구글 폼을 현재 앱 창에서 열도록 변경
3. 배포 후 설치된 앱에서 새로고침하고 실행 버전 67을 확인합니다.

실제 휴대폰 확인
- 설치된 앱 아이콘으로 시작합니다. 이전에 열어둔 구글 폼 창에서는 테스트하지 않습니다.
- 새 운동 구성 신청하기 → 새 신청서 작성하기 → 폼 제출 → 앱으로 돌아가기.
- 복귀 후 X 버튼이 있는 외부 창이 남지 않고 설치 앱 화면으로 돌아오는지 확인합니다.
- 구글 폼을 작성하는 동안 외부 사이트 주소/X 버튼이 보이는 것은 브라우저의 정상 표시입니다.
  이번 확인 대상은 앱 주소로 돌아온 뒤에도 그 외부 창이 남는 현상입니다.

검증 범위
- 로컬 브라우저에서 신규/기존 회원 모두 같은 창으로 폼을 열고 복귀하는 흐름을 확인합니다.
- 실제 구글 폼에 테스트 응답을 전송하거나 회원 데이터를 수정하지 않습니다.
- 안드로이드 설치 PWA의 외부 창 제어는 로컬 데스크톱 테스트로 재현되지 않습니다.
  위 휴대폰 테스트로 최종 확인해야 합니다.

기존 프로젝트 전체를 지우지 말고 해당 3개 파일만 교체합니다.
SQL 재실행은 필요 없습니다.
