알림 동작
- 하단 센터 커뮤니티: 미확인 센터 소식 수 + 새 답변이 있는 문의 수.
- 센터 소식: 미확인 소식 수. 게시글 제목이 화면에 보이면 읽음으로 처리합니다.
- 문의하기: 새 답변이 있는 문의 수. 같은 문의에 답변이 여러 개여도 문의 1건으로 셉니다.
- 문의 목록의 해당 항목에도 '새 답변'을 표시합니다.
- 문의 목록만 열어서는 읽음 처리하지 않습니다. 문의를 펼치고 답변이 화면에 보이면 읽음 처리합니다.
- 아래쪽에 가려져 아직 보지 않은 답변은 스크롤해서 확인해야 합니다.
- 이전 문의 더 보기로 불러오는 문의의 답변도 처음부터 배지 건수에 포함합니다.
- 미확인 항목이 없으면 배지가 사라집니다. 100건 이상은 99+로 표시합니다.
- 관리자 알림음과 데모 화면 등 기존 기능을 유지합니다. 회원용 알림음이나 푸시는 추가하지 않았습니다.

읽음 상태
- 회원 계정별로 현재 브라우저에 읽음 상태를 저장합니다.
- 같은 브라우저에서는 새로고침/로그아웃 후에도 유지하며, 다른 탭에도 반영합니다.
- 다른 기기나 브라우저에는 읽음 상태가 공유되지 않습니다.
- 처음 적용할 때는 과거 읽음 기록이 없으므로 기존 소식과 답변도 확인 전까지 배지에 포함됩니다.
- 브라우저 데이터를 삭제하면 읽음 기록도 초기화됩니다.
- 기존 실시간 연결로 변경을 확인하며, 앱에 다시 돌아오거나 연결이 복구될 때도 갱신합니다.

확인한 범위
- 실제 앱 파일을 로컬 브라우저에서 실행하고 모의 데이터로 테스트했습니다.
- 새 소식/답변, 실제 표시 후 읽음 처리, 새로고침, 회원 분리, 다중 탭,
  문의 목록 밖의 답변, 501개 답변 조회, 연결 복구, 조회 실패, 모바일 배치와 캐시 파일을 확인했습니다.
- 운영 데이터는 수정하지 않았습니다. 배포 후 실제 회원 계정으로 최종 확인해주세요.

배포 후 확인
1. 회원 앱에서 운동 구성 탭을 열어둡니다.
2. 관리자 계정으로 센터 소식을 게시하거나 해당 회원 문의에 답변합니다.
3. 회원 화면 하단 센터 커뮤니티와 내부 해당 탭에 빨간 숫자가 나타나는지 확인합니다.
4. 해당 소식/답변을 확인하면 배지가 사라지는지 확인합니다.
5. 새로고침한 뒤 읽은 항목이 다시 표시되지 않는지 확인합니다.
