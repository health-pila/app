v70: 삼성 인터넷 설치 전 사진 안내

기준
- 이 대화에서 수정한 v69를 기준으로 작성한 변경 파일 묶음입니다.
- v69의 문의 제목 제거, 내용 미리보기, 관리자 확인 화면 수정도 포함되어 있습니다.
- 전체 프로젝트가 아닙니다. 기존 폴더를 유지하고 아래 파일만 교체·추가하세요.

변경 내용
- 안드로이드 삼성 인터넷에서 기존 ‘이 앱을 홈 화면에 설치’ 버튼을 누르면 사진 안내가 열립니다.
- 1단계: 첫 번째 사진의 ‘세부정보 더보기’ 위치를 주황색 테두리로 표시합니다.
- 2단계: 두 번째 사진의 ‘무시하고 설치하기’ 위치를 표시합니다.
- 앱 이름이 ‘헬스와필라테스’인지 확인하라는 설명을 함께 표시합니다.
- ‘설치 시작하기’를 눌러야 기존 브라우저 설치 절차를 시작합니다.
- 설치 요청을 브라우저가 제공하지 않으면 기존처럼 브라우저 메뉴의 설치 항목을 안내합니다.
- 안내 닫기, 이전 단계, 다시 열기, 작은 화면의 스크롤을 지원합니다.
- 삼성 인터넷 외 브라우저와 아이폰은 기존 설치 흐름을 유지합니다.
- 이미 앱 모드로 실행 중인 경우 설치 버튼을 표시하지 않습니다.

적용 방법
1. 현재 프로젝트를 백업합니다.
2. 압축을 푼 뒤 위 기존 파일 5개를 프로젝트의 같은 위치에 덮어씁니다.
3. 사진 2개를 기존 images 폴더 안에 추가합니다.
   기존 images 폴더나 전체 프로젝트 폴더를 삭제하지 마세요.
   사진을 빠뜨리면 새 서비스워커의 캐시 준비가 실패할 수 있으니 함께 반영하세요.
4. Cursor에서 변경 내용을 확인한 뒤 커밋하고 GitHub에 푸시합니다.
   커밋명 예시: v70: 삼성 인터넷 설치 전 사진 안내 추가
5. 배포 완료 후 삼성 인터넷에서 기존 사이트를 새로고침합니다.
   예전 화면이 남아 있으면 브라우저 탭을 닫고 다시 접속해 주세요.

휴대폰에서 확인할 순서
1. 삼성 인터넷에서 로그인하고 기존 설치 버튼을 누릅니다.
2. 첫 사진의 강조 위치와 ‘다음 안내 보기’를 확인합니다.
3. 두 번째 사진의 강조 위치, ‘이전’, ‘닫기’를 확인합니다.
4. 안내를 다시 열어 ‘설치 시작하기’를 누릅니다.
5. 실제 차단 창이 나타나면 세부정보 더보기 → 무시하고 설치하기 순서로 진행합니다.
6. 홈 화면에 아이콘이 추가되고 앱이 열리는지 확인합니다.
7. 다른 브라우저 및 아이폰에서는 삼성용 사진 안내가 표시되지 않는지 확인합니다.

DB와 버전
- SQL 실행, Supabase 설정, Apps Script 수정은 필요 없습니다.
- 기존 운동·로그인·커뮤니티·관리자 업무 로직은 v69와 동일합니다.
- 캐시 버전은 70이며 새 사진 2개도 캐시에 포함합니다.
- reset-password.html은 공통 리소스의 캐시 버전만 맞췄습니다.

검증 범위
- JavaScript 문법 검사.
- 실제 HTML/CSS 및 설치 코드를 사용한 로컬 브라우저 테스트.
- 화면 너비 320/360/390px에서 사진 로딩, 스크롤, 아래 버튼 표시 확인.
- 단계 이동·닫기·Escape·다시 열기·키보드 포커스 이동 확인.
- 안내 완료 전 설치를 호출하지 않고 마지막 클릭에서만 호출하는지 확인.
- 설치 취소·오류·진행 중 중복 방지·설치 완료 이벤트를 모의 확인.
- 삼성 인터넷/Chrome/iOS 사용자 환경과 설치된 앱 모드를 모의 확인.
- 업데이트 중 이전 HTML이 남은 경우에도 기존 설치 흐름 유지 확인.
- 기존 업무 로직이 v69와 동일하고 캐시에 등록할 모든 파일이 존재하는지 확인.

확인해야 할 사항
- 브라우저 테스트의 설치 요청은 모의 이벤트이며 실제 Android 시스템 설치 시험은 아닙니다.
- 휴대폰·삼성 인터넷 버전에 따라 차단 안내의 문구나 모양이 다를 수 있습니다.
- 시스템 차단 창 자체를 바꾸거나 제거하는 수정이 아니라, 설치 전에 사진으로 안내하는 수정입니다.
- 운영 사이트 배포와 실제 삼성 휴대폰에서의 설치 확인은 위 적용 단계에서 진행해야 합니다.
- APPLY-v70.txt는 적용 안내용이며 앱 실행에는 필요하지 않습니다.
