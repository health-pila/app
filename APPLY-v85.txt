유산소 프로그램 — v85

적용 방법
1. 기존 앱 프로젝트 최상위 폴더에 아래 5개 파일을 교체합니다.
   index.html / script.js / style.css / reset-password.html / service-worker.js
2. 같은 폴더에 아래 2개 파일을 새로 추가합니다.
   cardio-programs.js / cardio-programs.css
3. 버전은 85로 맞춰져 있습니다. 데이터베이스나 SQL 변경은 필요 없습니다.
4. 모든 파일 저장 후 아래 명령으로 푸시합니다.

   git add index.html script.js style.css reset-password.html service-worker.js cardio-programs.js cardio-programs.css
   git commit -m "Add cardio program section v85"
   git push

변경 내용
- 운동 구성에 '나의 루틴 / 유산소 프로그램' 중분류를 추가했습니다.
- 처음 로그인하면 나의 루틴이 기본으로 열립니다.
- 유산소 프로그램에는 체중감량 3개, 체력강화 3개를 모두 표시합니다.
- 각 목적마다 저강도 / 중강도 / 고강도 프로그램이 있습니다.
- 이름, 추천 대상, 강도와 총 시간은 항상 보입니다.
- '운동 방법 보기'를 누르면 구간별 시간과 방법이 펼쳐집니다.
- 여러 프로그램을 동시에 펼칠 수 있으며, 다시 누르면 접힙니다.
- 루틴이 배정되지 않은 회원도 유산소 프로그램을 사용할 수 있습니다.
- 앱 안에서 다른 하단 탭을 다녀와도 선택한 중분류와 펼침 상태를 유지합니다.
- 앱 상단 새로고침 버튼 사용 시 선택한 중분류를 복원합니다. 펼침 상태는 초기화합니다.
- 로그아웃 후 다시 로그인하면 나의 루틴으로 돌아갑니다.
- 유산소 화면으로 이동하면 루틴 영상 재생은 정지합니다.
- 휴식 타이머는 나의 루틴에서 표시하며, 유산소 화면에서는 숨깁니다.
  진행 중인 타이머는 경과 시간을 유지하고 나의 루틴으로 돌아오면 다시 표시합니다.
- 기존 유산소 '준비 중' 안내와 그 전용 CSS는 제거했습니다.
- v84 로그인 보안 안내, 중량 기록, PT 장바구니, 데모, 커뮤니티 배지를 유지했습니다.

추후 운동 내용 수정
- cardio-programs.js 맨 위 CARDIO_PROGRAM_GROUPS에서 수정합니다.
- name: 프로그램 이름 / description: 추천 대상 / minutes: 총 소요 시간
- steps: [구간 이름, 운동 방법, 구간 시간]
- 총 시간과 구간 시간의 합을 함께 맞춰주세요.
- 운동 내용은 승인한 UI 초안에 들어 있던 내용을 사용했습니다.
- 디자인은 cardio-programs.css에 분리했습니다.

검증
- 실제 앱 코드를 로컬 브라우저에서 실행하고 회원 데이터는 모의 데이터로 확인했습니다.
- 320px / 390px / 1280px에서 6개 카드, 펼치기·접기, 키보드 탭 이동을 확인했습니다.
- 미배정 회원 접근, 중분류 유지·새로고침, 중량 기록·PT 장바구니 유지,
  영상 정지, 타이머, 로그아웃·재로그인, 데모·관리자 화면 진입을 확인했습니다.
- 기존 회원 커뮤니티 배지 테스트도 통과했습니다.
- 서비스워커의 새 파일 경로와 버전 85를 확인했습니다.
- 운영 데이터는 변경하지 않았습니다. 푸시 후 실제 모바일에서 최종 확인해주세요.
