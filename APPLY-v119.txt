센터앱 v119 교체 안내 (v118 기준)

휴식 타이머 드래그 이동
- 버튼을 짧게 누르면 열기·접기, 끌면 위치 이동
- 8px 이상 이동한 경우 드래그로 구분하고, 손을 뗀 직후 자동 클릭 방지
- 화면 밖·하단 대분류 메뉴 아래로 이동하지 않도록 제한
- 팝업은 공간에 맞춰 위/아래로 열리며, 높이를 제한하고 내부 스크롤 허용
- 가로 화면·화면 크기 변경·키보드 등 표시 영역 변화 시 위치 보정
- 위치를 저장하지 않음: 새로고침·앱 복귀·페이지 재표시 시 기본 위치로 복원
- 현재 앱에서 탭만 바꾸는 동안에는 이동한 위치 유지
- 시작·일시정지·초기화·+10초·시작 시 자동 접기 유지

아래 5개 파일을 기존 프로젝트 루트에 덮어쓴 뒤 커밋·푸시하세요.
index.html
style.css
script.js
reset-password.html
service-worker.js

APPLY-v119.txt는 안내문이므로 앱 폴더에 복사하지 않아도 됩니다.

검증
- JS 구문, 변경 파일 범위, 기존 HTML ID 보존
- 타이머 모듈 밖의 script.js 및 회원/루틴/저장 데이터 처리 코드 보존
- 모의 DOM에서 짧은 누름·드래그·즉시 재누름·키보드 클릭·포인터 취소
- 버튼/팝업 화면 경계, 화면 크기/표시 영역 변화
- 위치 초기화(앱 복귀·BFCache 복귀·새 실행), 위치 저장 기능 없음
- 시작·일시정지·초기화·프리셋·+10초·종료·자동 접기

실제 모바일 브라우저 검증은 수행하지 못했습니다.
배포 후 휴대폰에서 드래그, 짧게 누르기, 앱 복귀 시 기본 위치를 확인해 주세요.
